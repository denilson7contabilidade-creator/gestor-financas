# Gestor de Finanças

App de controle financeiro pessoal para celular, instalável pelo Chrome (Android).

- Os dados ficam **só no aparelho**, criptografados com a senha do usuário (AES-GCM, chave derivada por PBKDF2).
- Recuperação de senha por código de recuperação, criado junto com a conta.
- Despesas no cartão de crédito não saem do saldo; saem quando a fatura é paga.
- Funciona sem internet depois de instalado.
- Backup em arquivo para trocar de celular.

Este repositório guarda apenas o código do app. Nenhum dado financeiro é enviado para cá.
